# Farhan April Nurcahyo — Portfolio

A responsive, static portfolio website built for GitHub Pages. It uses plain HTML, CSS, and JavaScript; no build step or package installation is required.

## Deploy to GitHub Pages

1. Extract this ZIP into the root of your GitHub Pages repository.
2. Commit and push the files to the publishing branch configured in the repository's **Settings → Pages** (commonly `main`, the root folder).
3. Wait for GitHub Pages to publish the site, then open the repository's Pages URL.

The site works from a repository root and uses relative asset paths. The profile PDF is in `assets/Profile.pdf` and is linked from the hero section.

## Included

- Responsive single-page portfolio with dark and light themes.
- Mobile navigation and accessible section links.
- Profile portrait and downloadable source profile PDF.
- Content based on the supplied profile. No demo project screenshots are presented as actual work samples.
